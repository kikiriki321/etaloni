## 🇭🇷 Hrvatski

**Pronađite optimalnu kombinaciju paralelnih mjernih pločica (gauge blocks)**

### 📋 O programu

Alat za brzo i precizno izračunavanje kombinacija paralelnih mjernih pločica (etalona). Program automatski pronalazi optimalne kombinacije za željenu dimenziju.

### ✨ Značajke

- 🎯 **Automatski izračun** - Unesi dimenziju, dobij kombinaciju
- 🌍 **Višejezičan** - Hrvatski, Engleski, Njemački
- 🎨 **Dual theme** - Tamna i svijetla tema
- 📱 **Responzivan** - Radi na mobitelu, tabletu, računalu
- ⚡ **Offline** - Funkcionira bez internet veze
- 🔢 **Set od 87 pločica** - Standardni ISO set

### 🚀 Korištenje

1. Unesi željenu dimenziju (npr. `47.385`)
2. Klikni "Izračunaj kombinacije"
3. Dobij optimalne kombinacije pločica
4. Složi pločice prema rezultatu! ✅

### 🔧 Tehnički detalji

- **Max dimenzija:** 715.295 mm (zbroj svih pločica)
- **Preciznost:** Do 3 decimale (≤400mm), 2 decimale (>400mm)
- **Max pločica:** 12 po kombinaciji
- **Algoritam:** Optimizirani DFS (Depth-First Search)

### 💻 Instalacija

Jednostavno otvori link: https://kikiriki321.github.io/etaloni/

Ili preuzmi `index.html` i otvori u pregledniku (offline verzija).

## 🇬🇧 English

**Find the optimal combination of parallel gauge blocks**

### 📋 About

A tool for quick and precise calculation of parallel gauge block (slip gauge) combinations. The program automatically finds optimal combinations for the desired dimension.

### ✨ Features

- 🎯 **Automatic calculation** - Enter dimension, get combination
- 🌍 **Multilingual** - Croatian, English, German
- 🎨 **Dual theme** - Dark and light mode
- 📱 **Responsive** - Works on mobile, tablet, desktop
- ⚡ **Offline** - Functions without internet connection
- 🔢 **87-piece set** - Standard ISO set

### 🚀 Usage

1. Enter desired dimension (e.g. `47.385`)
2. Click "Calculate combinations"
3. Get optimal block combinations
4. Assemble blocks according to result! ✅

### 🔧 Technical details

- **Max dimension:** 715.295 mm (sum of all blocks)
- **Precision:** Up to 3 decimals (≤400mm), 2 decimals (>400mm)
- **Max blocks:** 12 per combination
- **Algorithm:** Optimized DFS (Depth-First Search)

### 💻 Installation

Simply open the link: https://kikiriki321.github.io/etaloni/

Or download `index.html` and open in browser (offline version).

## 🇩🇪 Deutsch

**Finden Sie die optimale Kombination von Parallelendmaßen**

### 📋 Über das Programm

Ein Werkzeug zur schnellen und präzisen Berechnung von Parallelendmaß-Kombinationen. Das Programm findet automatisch optimale Kombinationen für die gewünschte Dimension.

### ✨ Funktionen

- 🎯 **Automatische Berechnung** - Dimension eingeben, Kombination erhalten
- 🌍 **Mehrsprachig** - Kroatisch, Englisch, Deutsch
- 🎨 **Dual Theme** - Dunkler und heller Modus
- 📱 **Responsiv** - Funktioniert auf Handy, Tablet, Desktop
- ⚡ **Offline** - Funktioniert ohne Internetverbindung
- 🔢 **87-teiliger Satz** - Standard ISO-Satz

### 🚀 Verwendung

1. Gewünschtes Maß eingeben (z.B. `47.385`)
2. Auf "Kombinationen berechnen" klicken
3. Optimale Endmaß-Kombinationen erhalten
4. Endmaße nach Ergebnis zusammenstellen! ✅

### 🔧 Technische Details

- **Max. Dimension:** 715,295 mm (Summe aller Endmaße)
- **Präzision:** Bis zu 3 Dezimalstellen (≤400mm), 2 Dezimalstellen (>400mm)
- **Max. Endmaße:** 12 pro Kombination
- **Algorithmus:** Optimierte DFS (Depth-First Search)

### 💻 Installation

Öffnen Sie einfach den Link: https://kikiriki321.github.io/etaloni/

Oder laden Sie `index.html` herunter und öffnen Sie im Browser (Offline-Version).
