# ⚙️ Kalkulator mjernih pločica

**Pronađite optimalnu kombinaciju paralelnih mjernih pločica (gauge blocks)**

🌐 **Live demo:** https://kikiriki321.github.io/etaloni/

---

## 📋 O programu

Alat za brzo i precizno izračunavanje kombinacija paralelnih mjernih pločica (etalona). Program automatski pronalazi optimalne kombinacije za željenu dimenziju.

### ✨ Značajke

- 🎯 **Automatski izračun** - Unesi dimenziju, dobij kombinaciju
- 🌍 **Višejezičan** - Hrvatski, Engleski, Njemački
- 🎨 **Dual theme** - Tamna i svijetla tema
- 📱 **Responzivan** - Radi na mobitelu, tabletu, računalu
- ⚡ **Offline** - Funkcionira bez internet veze
- 🔢 **Set od 87 pločica** - Standardni ISO set

---

## 🚀 Korištenje

1. Unesi željenu dimenziju (npr. `47.385`)
2. Klikni "Izračunaj kombinacije"
3. Dobij optimalne kombinacije pločica
4. Složi pločice prema rezultatu! ✅

---

## 🔧 Tehnički detalji

- **Max dimenzija:** 715.295 mm (zbroj svih pločica)
- **Preciznost:** Do 3 decimale (≤400mm), 2 decimale (>400mm)
- **Max pločica:** 12 po kombinaciji
- **Algoritam:** Optimizirani DFS (Depth-First Search)
